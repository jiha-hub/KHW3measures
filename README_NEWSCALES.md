새 척도(PHQ-15, BDI-9, S-GDpS, K-MDQ, SSD-12)와 "검사 기록 삭제(숨김)" 기능은
`assessments` 테이블 구조를 확장합니다. **아래 SQL을 먼저 실행하지 않으면 새 척도 저장이 실패합니다.**

phpMyAdmin → (DB: `khw3`) → **SQL** 탭에 `migration4_newscales.sql` 내용을 붙여넣고 실행하세요.

```sql
ALTER TABLE assessments
    MODIFY scale_type ENUM(
        'PHQ-9','GAD-7','PSS-10','PSQI-K','CSEI-s',
        'PHQ-15','BDI-9','S-GDpS','K-MDQ','SSD-12'
    ) NOT NULL;
ALTER TABLE assessments
    ADD COLUMN IF NOT EXISTS deleted_at DATETIME NULL DEFAULT NULL AFTER created_at;
CREATE INDEX idx_assessments_deleted ON assessments(deleted_at);
```
(마지막 인덱스 줄에서 "이미 존재" 오류가 나면 무시하고 넘어가세요.)

## 추가된 척도 5종 (근거 기반 채점)

| 척도 | 문항/응답 | 총점 | 절단점·해석 | 근거 |
|------|-----------|------|-------------|------|
| **PHQ-15** 신체증상 | 15문항 (0·1·2) | 0–30 | 5/10/15 = 최소·경도·중등도·고도. **절단점 10** | Kroenke 2002 / 한국판 한창수 |
| **BDI-9** 자살사고 | 1문항 (0~3) | 0–3 | 1점 이상 = 자살사고 있음(안전평가). **긴급 플래그** | BDI 9번 문항 |
| **S-GDpS** 노인우울 | 15문항 예/아니오 | 0–15 | **절단점 8** (SGDS-K) | Sheikh&Yesavage GDS-15 / SGDS-K 조맹제 |
| **K-MDQ** 양극성 선별 | 13문항 예/아니오 | 0–13 | **7개 이상 = 선별 양성** | 전덕인 2009 / Hirschfeld 2000 |
| **SSD-12** 신체증상장애 B기준 | 12문항 (0~4) | 0–48 | 0–17 정상 / 18–28 주의 / 29+ 위험. 국제 절단점 23 | Toussaint 2016 |

> 채점 로직은 `scales.php`의 `calculateScore()`가 처리합니다.
> - **S-GDpS**: 문항별 채점 방향이 다릅니다(긍정문항 1·5·7·11·13번은 「아니오」가 1점). `item_scores`로 구현.
> - **PHQ-15**: 문항 4(생리통)는 **여성만** 응답하고 남성은 자동 0점·화면에서 건너뜁니다.
> - **SSD-12**: 인지/정서/행동 3개 하위영역 점수를 함께 저장·표시합니다.
> - **BDI-9**: 1점 이상 시 안전 플래그(주의/긴급)를 표시합니다.

**⚠️ 모든 문항 문안·절단점은 표준 검증판을 근거로 작성했습니다. 임상·연구 사용 전 보유하신 공식 문서와 한 문항씩 대조·검수하시고, 척도별 저작권/사용 조건을 확인하세요.**

## 앱 개선 사항 (요청 반영)

1. **피츠버그(PSQI) 문항 보강**: 원 설문의 **문항 10(동거인/잠자리 공유 + 관찰 항목 a~e)**를 참고(선택) 문항으로 추가했습니다. 이 문항은 표준 PSQI 채점(7개 구성요소·총점 0~21)에는 **포함되지 않습니다**(원판과 동일). 채점 로직은 그대로이며 검증된 기준은 절단점 5점 하나입니다.
2. **문항별 차등 채점 확인**: PSS-10(역채점 4·5·7·8번)과 PSQI(같은 응답이라도 구성요소별로 다른 채점 경로)는 이미 문항별로 다르게 채점됩니다. S-GDpS도 `item_scores`로 동일하게 구현했습니다.
3. **PSQI 5-j 주관식**: "수면을 방해한 그 밖의 이유"를 자유롭게 입력하는 칸을 추가했습니다(응답 배열 마지막에 저장, 채점 미포함).
4. **사이드바 + 문항박스**: 검사 화면 왼쪽에 **현재 검사 이름**, **응답 기간(예: 지난 2주/지난 한 달)**을 크게 표시하고, 공통 안내 문구를 사이드바의 "문항 안내"로 옮겼습니다. 태블릿·모바일에서는 상단 카드로 접힙니다. PSQI 화면에도 "응답 기간" 배너를 추가했습니다.
5. **검사 취소/건너뛰기**: 검사 중 왼쪽(또는 하단) "이 검사 취소하고 다음으로" 버튼으로 현재 검사를 **저장하지 않고** 다음 검사로 넘어갈 수 있습니다(연속검사). 단독 검사에서는 검사를 취소하고 나갑니다.
6. **검사 기록 삭제(숨김)**: 이력 화면과 상세 모달에 삭제 버튼을 추가했습니다. **완전 삭제가 아닌 소프트 삭제(숨김)** 방식이라, 의료·연구 데이터가 보존되고 "🗑️ 숨김 기록 보기"에서 언제든 복구할 수 있습니다.
7. **중한 결과 색상 변경**: 환자 불안 완화를 위해 "중한 우울·고도·위험군·선별 양성" 등 **모든 중한 결과를 붉은색 대신 검정 계열**로 표시합니다(이력·그래프·요약·완료 화면 전반).
8. **터치·반응형·유니버설 디자인**: 예/아니오 큰 버튼, 세로 버튼(긴 보기), 세그먼트 바, 글자 크게 모드를 척도 유형에 맞게 적용했습니다.
