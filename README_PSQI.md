# PSQI-K 추가 안내

한국판 피츠버그 수면의 질 지수(PSQI-K)를 기존 앱에 추가했습니다. 기존 PHQ-9 / GAD-7 / PSS-10 엔진은 **전혀 수정하지 않았고**, PSQI-K는 별도 모듈로 분리해 동의 흐름·그래프·이력·크기조절에만 연결했습니다.

## 배포 순서 (중요)

1. **DB 마이그레이션을 먼저 실행하세요.** 코드가 배포된 뒤 마이그레이션 전에 검사가 저장되면 실패합니다.
   Railway MySQL 콘솔에서:
   ```sql
   ALTER TABLE assessments
     MODIFY COLUMN scale_type ENUM('PHQ-9','GAD-7','PSS-10','PSQI-K') NOT NULL;
   ```
   (`migration_psqi.sql` 파일과 동일)

2. 파일을 GitHub에 올리면 Railway가 자동 배포합니다. `config.php`는 **덮어쓰지 마세요** (로컬 DB 자격증명 보호).

## 채점 방식

18개 응답 → 7개 구성요소(각 0~3점) → 총점 0~21점.

- **구성요소 1** 주관적 수면의 질 (문항 6)
- **구성요소 2** 수면 잠복기 (문항 2 분 + 문항 5a)
- **구성요소 3** 수면 시간 (문항 4)
- **구성요소 4** 수면 효율 (취침·기상 시각으로 침대에 누운 시간 계산 → 실제 수면시간 ÷ 침대시간)
- **구성요소 5** 수면 방해 (문항 5b~5j 합산)
- **구성요소 6** 수면제 사용 (문항 7)
- **구성요소 7** 주간 기능장애 (문항 8 + 문항 9)

절단점: **총점 5점 초과 시 수면의 질 저하**로 해석 (Sohn 외, 2012).
5점 초과 구간의 세부 밴드(경도/저하)는 시각화 편의용이며, 검증된 기준은 절단점 5점 하나입니다.

## ⚠️ 반드시 확인할 것

- **문항 문안**: `psqi_scoring.php`의 `items` 배열에 있는 문항 텍스트는 표준 검증판을 참고한 것입니다. **보유하신 공식 문서와 한 문항씩 대조·검수한 뒤 임상에 사용하세요.** 문안 수정은 이 배열 한 곳만 고치면 됩니다.
- **저작권**: PSQI/PSQI-K는 원저자 및 한국판 저작권이 있습니다. 실제 임상·연구 사용 시 라이선스를 확인하세요.
- 배포 후 **테스트 케이스 1건**을 직접 입력해 총점·구성요소·이력·그래프가 정상 동작하는지 확인하시길 권합니다.
